# สิ่งที่ต้องมีก่อนขึ้นจริง

เว็บนี้ build ได้และดูสมบูรณ์ในโหมด placeholder แต่ยังไม่พร้อมขึ้น production
จนกว่าจะเปลี่ยนของด้านล่างเป็นของจริง

## 1. ภาพถ่าย

โหมดปัจจุบันใช้ภาพ SVG ที่ generate จาก seed ใน `src/content/media.ts`
(`npm run media`) ไม่มีเครื่องมือ generate ภาพในสภาพแวดล้อมนี้ และ
`picsum.photos` กับ `images.unsplash.com` ถูก network policy บล็อก

เปลี่ยนเป็นภาพจริงได้สองทาง

1. วางไฟล์จริงลง `public/media/<seed>.jpg` แล้วแก้ `src/lib/media.ts` ให้ชี้นามสกุลใหม่
2. หรือรันด้วย `NEXT_PUBLIC_IMAGE_MODE=remote` เพื่อดึงภาพ stock ตาม seed ระหว่างทำ demo

รายการภาพและ art direction ของแต่ละช่องอยู่ในฟิลด์ `brief` ของ
`src/content/media.ts` ทุก slot สรุปคือ

| slot | ใช้ที่ไหน | อัตราส่วน |
|---|---|---|
| `home-hero` | hero หน้าแรก | 4:3 |
| `home-agent-band` | แถบชวนสมัครนายหน้า หน้าแรก | 16:9 |
| `product-*` | การ์ดสินค้าและหัวหน้ารายละเอียด | 3:2 |
| `about-office`, `about-story` | หน้าประวัติบริษัท | 16:9 / 4:3 |
| `agent-hero` | hero หน้าสมัครนายหน้า | 16:9 |
| `leader-1..4` | ทีมผู้บริหาร | 1:1 |
| `testimonial-1..3` | เสียงลูกค้า | 1:1 |

## 2. ข้อมูลบริษัทจริง

`src/content/company.ts` เป็นข้อมูลสมมติทั้งไฟล์ ต้องเปลี่ยน

- ชื่อบริษัทตามที่จดทะเบียน
- เลขที่ใบอนุญาตนายหน้าประกันวินาศภัย และปีที่ออก
- เลขทะเบียนนิติบุคคล ทุนจดทะเบียน
- ที่อยู่ เบอร์โทร อีเมล LINE OA
- รายชื่อสาขาและเวลาทำการจริง

## 3. โลโก้

`src/components/site/logo.tsx` เป็น mark ที่วาดขึ้นเองสำหรับแบรนด์สมมติ
ถ้าใช้แบรนด์จริง ให้แทนที่ด้วยไฟล์โลโก้จริง และตรวจว่าอ่านออกทั้งพื้นสว่างและพื้นเข้ม

## 4. โลโก้บริษัทประกันคู่สัญญา

`src/content/partners.ts` เป็นชื่อบริษัทประกันที่สมมติขึ้น เพราะใช้โลโก้ของ
บริษัทประกันจริงไม่ได้ถ้ายังไม่ได้รับอนุญาต เมื่อได้รับอนุญาตแล้วให้เปลี่ยนเป็น
ไฟล์โลโก้จริง และคง logo wall ให้มีแต่โลโก้ ไม่ต้องมีป้ายกำกับประเภทธุรกิจใต้โลโก้

## 5. ปลายทางของฟอร์ม

- ฟอร์มสมัครนายหน้า `/agent/apply` ตอนนี้ validate ครบและส่งเข้า server action
  ที่ยังไม่ได้ต่อกับระบบหลังบ้าน ต้องต่อกับ CRM หรือ endpoint จริง
- ฟอร์มติดต่อ `/contact` เหมือนกัน
- ทั้งสองฟอร์มเก็บข้อมูลส่วนบุคคล ต้องมีนโยบายความเป็นส่วนตัวและ consent
  ตาม PDPA ก่อนเปิดใช้จริง

## 6. หน้าที่ยังไม่มี

- นโยบายความเป็นส่วนตัว
- ข้อกำหนดการใช้งาน
- หน้าข่าวสารหรือบทความ ถ้าต้องการทำ SEO ระยะยาว
